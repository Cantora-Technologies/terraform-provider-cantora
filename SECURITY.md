# Security policy

Do not report a vulnerability in a public issue.

Email `security@cantora.ai` with a description, reproduction steps, affected versions, and any known impact. Do not include live credentials or customer data. Cantora will acknowledge the report, coordinate validation and remediation, and arrange disclosure after a fix is available.

Only supported versions listed in the Terraform Registry receive security fixes. If a release is defective, Cantora publishes a new version; published tags, archives, checksums, and signatures are never replaced.
